api
: 命名空间 → 对象. 每个命名空间成为模块
acde:<命名空间>
, 对象上的函数成为可调用的方法, 字符串 / 数字 / 布尔值成为只读字段.
sync
:
"命名空间.方法"
的列表. 这些方法在页面启动时调一次, 结果缓存在页面里, 之后在页面里同步返回 (适合不变的配置).
close()
: 桌面停止时调用.
应用把
服务名
(桌面配置
services
的键) 列在自己的
services
里, 运行时就把这个服务的所有命名空间都给它. 导入的命名空间不是服务自己的名字时,
acde check
和
acde build
让它通过, 带一条
note:
, 因为它们没法知道一个服务有哪些命名空间 (见
服务
). 服务名不能是系统模块或能力的名字, 取了这种名字的命名空间会被略去.
import('acde:windows')
: 桌面把这个模块给了这个服务时, resolve 成这个模块 (
{ windows, default }
): 在
acde.config.jsonc
里写
"services": { "clock": { "module": "services/clock.ts", "modules": ["windows"] } }
,
acde build
把它写进清单, 成为
"services": [{ "name": "clock", "modules": ["windows"] }]
(见
包清单
). 否则 reject, 错误信息是
acde:windows is a shell module: list it in the modules of service "clock" in the desktop manifest
. 服务不能用静态
