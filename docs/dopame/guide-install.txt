本机安装
acde dev
只是临时把应用交给运行时. 想让应用一直出现在本机的 Dopame 桌面里:
终端窗口
acde
install
它先
acde build
, 再把包装进
$XDG_DATA_HOME/acde/packages/<id>
(默认
~/.local/share/acde/packages/<id>
, Windows 上是
%USERPROFILE%\.local\share\acde\packages\<id>
). 先复制到临时目录再整体替换, 不会留下半个包. 手写的包 (没有配置、
package.json
里自带
acde
清单) 装成指向工程的符号链接.
装好后, 下次启动的会话 (以及
acde dev --desktop dopame
) 就能看到它.
找包
找包 一节的链接
按顺序, 同一个 id 先找到的为准:
ACDE_PATH
里的目录 (
acde dev
用它交出构建结果);
$XDG_DATA_HOME/acde/packages/*
;
$XDG_DATA_DIRS/acde/packages/*
(系统级安装).
卸载
卸载 一节的链接
删掉
$XDG_DATA_HOME/acde/packages/<id>
.
发布
发布 一节的链接
应用商店和
acde publish
还在做. 现在分发应用就是分发构建出的包目录 (
.acde/
), 放进上面任意一个位置即可.
