运行时只在 GPU 上画页面, 没有 GPU 的 Linux CI 跑不了 headless. macOS 的 CI runner 可以.
Linux 上运行时需要机器 GPU 的
硬件 Vulkan 驱动
; 软件渲染器 (lavapipe / llvmpipe) 不行. 没有驱动时
acde dev
启动就失败, 日志里有一行说明这一点, 并指出系统里有的是哪块 GPU:
web layer unavailable: the system has a GPU (card0, kernel driver i915) but no usable Vulkan driver was found: install the GPU's Vulkan driver (for example vulkan-intel, vulkan-radeon, nvidia-utils) or point VK_DRIVER_FILES at its ICD (…)
. 解决办法是装上驱动, 再确认

vulkan-radeon
