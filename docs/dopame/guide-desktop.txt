在桌面里开发
桌面
Dopame OS 的桌面本身也是一个 acde 工程: 一张铺满屏幕、在所有窗口后面的网页. 桌面能导入这个平台上除
acde:window
(它是给应用窗口用的) 以外的所有
acde:
模块, 包括应用拿不到的 shell 模块, 负责 Dock、菜单栏、窗口切换、通知、批准提示这些「系统界面」. Dopame 自带的桌面叫
dopame
; 你可以做自己的.

系统应用
系统应用 一节的链接
桌面的
apps
里的应用和桌面在同一个包里, 所以是
系统应用
. 它们和别的应用有三点不同:
可以把 shell 模块声明成能力并导入:
"capabilities": { "windows": true, "permissions": true }
. 不在桌面包里的应用声明了 shell 模块, 过不了
acde check
(
acde:windows is a shell module: only apps of a desktop package (system apps) may declare it
).
它们的能力不用用户批准.
fs.roots
里写了共享位置时, 它们的
acde:fs
根带着文件夹的
path
,
fs.locate()
/
fs.openPath()
也能用.
系统应用只能导入它声明了的模块: 没写
"session": true
就
import 'acde:session'
会失败, 报
acde:session is a shell module: declare "session" in the capabilities of <label>
.
