应用 一节的链接
Dopame OS 的桌面本身就是一张网页, 桌面上的每个窗口也是. 一个
应用
就是一个网页工程: HTML、CSS、JS, 可以用 React、Vue、Svelte、Next.js、Nuxt、Astro 等任何框架写, 可以带一个用 Bun 或 Node.js 跑的后端.
和浏览器里不同的是, 应用能在配置 (
acde.config.jsonc
) 里申请
系统能力
, 比如读写用户的文件夹、开终端、打开别的应用. 这些能力不放在全局对象上, 而是像 Node.js 的
node:fs
一样, 从
acde:
内置模块导入:

{ fs }

'

roots

除此之外, 页面里绝大多数是标准 Web 接口: DOM、
fetch
、
localStorage
、IndexedDB、Web Audio 等, 行为和浏览器一致. 例外 (比如没有 Web Worker 和 WebGL, 不能从外站导入 ES 模块) 列在
Web 兼容性
里.
两个工具
两个工具 一节的链接
是什么
类比
acde
开发者命令行: 新建工程、构建、开发会话、调试、测试
wrangler
acdert
运行时: 跑桌面和应用的那个程序. Dopame OS 的会话 (用户登录后屏幕上的一切) 就是它
workerd
简单说:
acde
是你在终端里敲的命令, acdert 是真正把应用跑起来的程序.
开发时你只和
acde
打交道.
acde dev
会构建你的工程并拉起 acdert, 在你的电脑上开一个窗口, 里面是你的应用 (加
--desktop dopame
时是 Dopame 的桌面和你的应用); 改了代码自动重新构建、重新载入. acde 的安装器会把和它配对的那一版 acdert 装在它旁边, 所以装完就能
acde dev
; 见
安装
.
