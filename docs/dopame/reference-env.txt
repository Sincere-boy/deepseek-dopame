变量
作用
ACDE_INSTALL
安装目录, 默认
~/.acde
ACDERT
acde dev
和
acde test
跑的 acdert 二进制: 一个路径, 或 PATH 上的名字. 没设: 安装脚本装在 acde 旁边的 acdert, 再是 PATH 上的
acdert
ACDE_BUNDLER=vite
Bun 上也用 Vite 打包
ACDE_API
acde new
写进
@dopame/acde-api

https://pkgs.dopame.ai/acdert/<版本>/
上和这一版 acde 对应的 SDK tarball)
CI
设了时
toHaveScreenshot
不会写新的基线, 缺基线直接失败

作用
ACDE_PATH

;
分隔)

ACDE_HEADLESS=1
不开窗口

屏幕尺寸, 如
1280x800
ACDE_SCALE
headless 时的缩放 (0.5–4)

light
/
dark
ACDE_REDUCED_MOTION
1
/
0

网页存储的根目录; 设成空则只在内存
ACDE_AUTOSTART
0

ACDE_AUDIO=null
不出声

Fake camera
、
Fake microphone

getUserMedia()
用
ACDE_FRAME_STYLE
标题栏样式: mac 的红绿灯或 Windows 的按钮
