窗口
每个应用窗口是一张独立的网页, 有自己的 DOM 和 JS 堆; 一个窗口崩溃不影响别的. 同一个应用的所有窗口共享
localStorage
、IndexedDB、cookie 等存储.
尺寸和标题栏
尺寸和标题栏 一节的链接
在桌面里, 新窗口的内容区是配置的
size
(默认 800 × 600), 居中打开; 下次打开时摆回上次关闭的位置.
只跑一个应用的
acde dev
会话里 (应用工程, 没带
--desktop
), 应用
铺满宿主窗口
,
size
决定宿主窗口打开时有多大: 配置是
"size": [400, 300]
时, 宿主窗口的内容区是 400 × 300. 标题栏画在内容区里面, 所以页面是 400 × 268. 没写
size
时, 宿主窗口占屏幕的大部分 (宽的 90%、高的 85%, 最大 1440 × 900).
acde dev --headless
没有宿主窗口,
size
不起作用: 屏幕是 1440 × 900 (
acde test
里是 1280 × 800), 应用铺满它, 所以页面是 1440 × 868. 想看应用在按它自己的
size
开的窗口里的样子, 让它跑在桌面里:
acde dev --desktop ./my-desktop
, 或装了那个桌面之后用
--desktop dopame
(见
acde dev
).

一个任务跑超过 5 秒, 桌面会收到「无响应」, 可以结束它.
