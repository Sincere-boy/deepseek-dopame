编码 agent
acde 自带一个
skill
: 一份说明加一组参考文件, 教编码 agent (Claude Code、Codex、Cursor、Gemini CLI, 以及其他读
Agent Skills
格式的 agent) 怎么新建、运行、查看和测试 acde 工程. skill 在 acde 的归档里, 所以它说的总是你装的那一版 acde. 这份文档也是从同一批文件生成的.
一句话配好
一句话配好 一节的链接
把这句话贴给你的 agent:
Read https://pkgs.dopame.ai/acde/install.md and follow it to set up acde on this machine.
它会安装 acde, 给自己装上 skill, 再汇报哪些就绪、哪些还缺.
自己装 skill
自己装 skill 一节的链接
终端窗口
acde
skills
install
它把 skill 链接到:
~/.agents/skills/acde
, 按通用约定读 skill 的 agent 共用的目录 (Codex、Cline、Zed、Warp、Pi 等);
本机上找到的其他每个 agent 的 skills 目录, 比如 Claude Code 的
~/.claude/skills/acde
, Cursor 的
~/.cursor/skills/acde
.
每一处都是指向 acde 安装目录里那份 skill 的链接, 所以升级 acde 也就升级了 skill.
命令
做什么
acde skills
列出 skill 装在哪些地方, 每一处是不是最新的
acde skills install
给找到的每个 agent 装上
acde skills install --agent claude-code,cursor
给这几个 agent 装, 不管找没找到
acde skills install --dir DIR
装进
DIR/acde
; 用于 acde 不认识的 agent, 或工程自己的 skills 目录 (比如
.agents/skills
)
acde skills install --copy
拷贝而不是链接; 用于不能跟随链接的 agent. 升级 acde 后要再跑一次
acde skills remove
从装过的地方都删掉 (自己指定过的目录加
--dir DIR
);
acde skills install
在那些地方建的 skills 目录空了以后也一起删掉
acde skills path
打印 acde 安装目录里 skill 的目录
acde skills install
不会替换一个名叫
acde
但不是这个 skill 的目录; 它会停下并指出是哪个.

不支持 skill 的 agent 一节的链接
让 agent 去读 skill 的入口文件. 比如在工程的
AGENTS.md
里写:
This is an acde project. Before working on it, read the file SKILL.md in the directory `acde skills path` prints.
